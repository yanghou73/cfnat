# cfnat - Cloudflare IP 筛选与转发工具管理脚本

> cfnat 是一款基于 Shell 脚本的管理工具，用于自动下载、配置、运行和维护 cfnat（Cloudflare IP 筛选与转发工具）。它提供了交互式菜单，简化了部署、配置和日常运维的流程。

## ✨ 功能特性

- **一键安装与卸载**：自动检测系统架构，从 GitHub 下载对应版本的二进制文件和配置模板。
- **交互式菜单**：所有操作（启动、停止、重启、配置等）均可通过菜单完成，无需记忆复杂命令。
- **IP 库自动更新**：支持从多个 IP 源（AS13335, AS209242 等）并行下载、合并和去重 Cloudflare IP 列表。
- **定时保活**：通过 `crontab` 实现进程守护，服务崩溃自动拉起。
- **定时更新**：支持配置每日定时更新 IP 库，并在服务运行时自动重启以加载新 IP。
- **Docker 环境感知**：兼容 Docker 部署模式，自动检测并避免端口冲突。
- **优雅的安全机制**：所有破坏性操作（卸载、停止等）均需二次确认，防止误操作。

## 🚀 快速开始

### 1. 下载并运行脚本

在 Linux 终端执行以下命令即可一键下载脚本并启动：

```bash
# 下载脚本
curl -O https://raw.githubusercontent.com/yanghou73/cfnat/main/cfnat.sh

# 运行脚本
bash cfnat.sh
```

### 2. 首次使用

运行脚本后，将进入交互式菜单。

- 如果是**首次安装**，请选择 `1` (一键安装)，脚本会自动下载所需文件。
- 如果已经安装，选择 `2` (启动 cfnat) 即可开始服务。

## 📖 菜单说明

脚本主菜单包含以下选项：

| 选项 | 功能 | 说明 |
| :--- | :--- | :--- |
| `0` | 退出脚本 | 退出管理工具 |
| `1` | 一键安装/卸载 | 首次使用请选择此选项进行安装 |
| `2` | 启动 cfnat | 启动转发服务（后台运行） |
| `3` | 停止 cfnat | 停止当前运行的服务 |
| `4` | 重启 cfnat | 先停止再启动服务 |
| `5` | 配置 cfnat | 交互式修改配置文件（端口、延迟、数据中心等） |
| `6` | 调试运行 | 前台运行服务，便于查看实时日志和调试 |
| `7` | 手动设置架构 | 手动选择系统和架构（通常无需使用） |
| `8` | 更新 IP 库 | 立即从多个源下载最新的 IP 列表并合并 |
| `9` | 定时更新设置 | 设置每日自动更新 IP 库的时间 |
| `10` | Docker 部署 | 预留入口，用于 Docker 容器化部署（未来版本） |

## ⚙️ 配置文件说明

cfnat 的配置文件为 `cfnat.conf`，首次安装时会自动下载。以下是常用配置项：

- `colo`: **数据中心筛选**。默认包含全球 20 个关键节点（如 `SJC,LAX,HKG`），建议根据你的网络环境进行精简，以获得更好的连接质量。
  - **电信用户**：推荐使用美西节点，如 `SJC,LAX,SEA`
  - **移动/联通用户**：推荐使用亚太节点，如 `HKG,NRT,SIN`
- `port`: **本地监听端口**。默认 `1234`。
- `delay`: **有效延迟**。超过此延迟的连接将被丢弃，默认 `300` (毫秒)。
- `auto_update_hour`: **定时更新时间**。每日自动更新 IP 库的小时（0-23），默认 `4` (凌晨4点)。

你可以通过菜单 `5` (配置 cfnat) 来交互式地修改这些参数。

## ⏱️ 定时任务

安装并启动服务后，脚本会自动在 `crontab` 中注册以下两个定时任务：

1.  **保活任务** (`*/5 * * * *`)：每 5 分钟检测一次 cfnat 进程，如果服务意外停止，会自动拉起。
2.  **定时更新任务** (`0 $auto_update_hour * * *`)：在你设置的时间（默认凌晨4点），自动更新 IP 库并重启服务以加载新 IP。

## 🐳 Docker 部署 (规划中)

本脚本已预留对 Docker 环境的支持。当检测到 Docker 环境时，脚本会：
- 自动检测运行中的 `cfnat` 容器，避免端口冲突。
- 在更新 IP 库时，自动重启容器而非脚本进程。

## 📝 常见问题

**Q: 运行脚本提示下载失败怎么办？**
A: 可能是网络问题。请检查 `cfnat.conf` 中的 `github_proxy` 是否配置正确。如果在国内，建议使用代理，如 `https://ghfast.top/`。

**Q: 如何停止服务？**
A: 在脚本菜单中选择 `3` (停止 cfnat)。这不仅会停止进程，还会清除定时任务。

**Q: 如何查看实时日志？**
A: 在脚本菜单中选择 `6` (调试运行)。这会在前台运行服务，可以直接看到所有输出日志。按 `Ctrl+C` 可返回菜单。
